## 🧑‍🎓 About the Project

**LearnEd** is a modern, responsive **e-learning website** template — home page, course catalogue, instructors, testimonials and contact — built with HTML, CSS, JavaScript and Bootstrap. Ideal as a front-end showcase or the UI layer of a full LMS project.

## ✨ Key Features

- 🏠 Attractive landing page with hero banner
- 📚 Course catalogue & category cards
- 👨‍🏫 Instructors and testimonials sections
- 📬 Contact form
- 📱 Mobile-first responsive layout

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | HTML5 · CSS3 · JavaScript |
| UI Framework | Bootstrap |
